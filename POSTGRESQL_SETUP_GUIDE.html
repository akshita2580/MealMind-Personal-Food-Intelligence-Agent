🐘 PostgreSQL Setup Guide

Choose the best option to set up your production database

⚠️ Why PostgreSQL?

SQLite is only for local testing! For a production-ready app that syncs with actual Swiggy:

  • ✅ PostgreSQL handles multiple users concurrently
  • ✅ Better performance and reliability
  • ✅ Cloud-ready for deployment
  • ✅ Full ACID transaction support

Choose Your Setup Method:

Option 1: Neon (Cloud PostgreSQL)

Best for: Everyone - Free, fast, no credit card required

Setup time: 3 minutes

1 Create Account
Open Neon.tech →

Click "Sign Up" and use GitHub/Google

2 Create Project

• Name it "MealMind"

• Copy the connection string they show you

3 Update .env File

Replace DATABASE_URL=data/swiggy.db with:

DATABASE_URL=postgresql+psycopg://[paste-your-neon-url-here]

⚠️ Important: Make sure to add +psycopg after postgresql!

4 Migrate Data
python migrate_sqlite_to_postgres.py
5 Restart Backend
python -m src.main

Option 2: Supabase (Cloud PostgreSQL)

Best for: If you want additional features like storage and auth

Setup time: 5 minutes

  1. Go to supabase.com
  2. Create a new project
  3. Settings → Database → Copy "Connection string"
  4. Update .env (add +psycopg to the URL)
  5. Run: python migrate_sqlite_to_postgres.py

Option 3: Docker (Local PostgreSQL)

Best for: Development if you have Docker Desktop

Requirements: Docker Desktop must be running

Run these commands:

# Start Docker Desktop first, then:
python auto_setup_postgres.py

This will automatically:

  • Create a PostgreSQL container
  • Update your .env file
  • Test the connection

✅ After Setup

Once PostgreSQL is configured:

  1. Migrate your data: python migrate_sqlite_to_postgres.py
  2. Restart backend: Stop (Ctrl+C) and start python -m src.main
  3. Test your app: Login and verify all features work

💡 Need Help?

If you run into issues:

  • Check that the DATABASE_URL has +psycopg in it
  • Verify PostgreSQL is accessible (for Docker, check Docker Desktop)
  • Run: python -c "from src.database import get_engine; get_engine().connect()"
